BACKEND DEV SETUP (DEBIAN/UBUNTU)

Script único para preparar uma máquina limpa para desenvolvimento.

Linguagens

* Java 21 (LTS)
* Node.js LTS
* Yarn
* Go
* Rust (cargo/rustup)
* Python 3 + pip + venv

Bancos

* PostgreSQL
* MySQL (MariaDB)

Infra

* Docker Engine
* Docker Compose
* ngrok (túnel HTTP)

Ferramentas

* git
* build-essential
* curl / wget
* unzip / zip
* flatpak
* gnome-terminal

Apps (Flatpak)

* Visual Studio Code
* Postman
* Beekeeper Studio
* Wireshark
* Telegram
* Discord
* Flatseal

Dar permissão:
chmod +x run.sh

Executar:
./run.sh
